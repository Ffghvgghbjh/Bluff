# BLUFF / ბლეFი — ონლაინ ვერსია

ბლეფის კარტის თამაში 2–6 მოთამაშისთვის (ქართული და ინგლისური ენა). მეგობარს მხოლოდ ბმული სჭირდება.

## ფაილები
- `server.js` — სერვერი: ოთახები, თამაშის წესები, ბოტები
- `public/index.html` — თამაშის გვერდი (მთავარი, ლობი, მაგიდა, ენები)
- `package.json` — საჭირო პროგრამის სია

## ადგილობრივად გამოსაცდელად
1. დააინსტალირე Node.js 18+ (nodejs.org).
2. ამ საქაღალდეში: `npm install`, შემდეგ `npm start`.
3. გახსენი http://localhost:3000 (ორ ჩანართში შეგიძლია ორი მოთამაშე ითამაშო).

## ინტერნეტში განთავსება (Render, უფასოდ)
1. ატვირთე საქაღალდის შიგთავსი GitHub-ის საცავში (`node_modules` არ სჭირდება).
2. Render → New + → Web Service → აირჩიე საცავი.
3. Build Command: `npm install`, Start Command: `npm start`, Instance Type: Free.
4. განახლებისას საკმარისია GitHub-ზე ფაილების ჩანაცვლება: Render თავისით ახლდება.

## რა იცის
- ოთახის შექმნა, ბმულით ან კოდით შესვლა, ბმულის გაზიარება
- 0–5 ბოტი (სულ მაქსიმუმ 6 მოთამაშე), ბოტების მართვა ლობიში
- 15-წამიანი ტაიმერი გამოწვევასა და ბლოკზე, კარტის გამოვლენის ეფექტი
- სწრაფი რეაქციები (ემოჯი), „ხელახლა თამაში“ იმავე ოთახში
- გათიშვის შემდეგ ავტომატური დაბრუნება (გვერდის გადატვირთვაც შეიძლება)
- თუ მოთამაშე 60 წამს არ პასუხობს ან გავა, მის ადგილს ბოტი იკავებს
- ტექსტები ენაზე დამოუკიდებლად იგზავნება, ამიტომ ენის შეცვლა თამაშის შუაშიც შეიძლება

## შეზღუდვები
- ოთახები სერვერის მეხსიერებაშია: სერვერის გადატვირთვისას მიმდინარე თამაშები იშლება.
- უფასო Render 15 წუთის უმოქმედობის შემდეგ იძინებს, პირველი გახსნა ~50 წამს დასჭირდება.
