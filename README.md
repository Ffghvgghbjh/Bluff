# ბლეFი — ონლაინ ვერსია

ბლეფის თამაში 2–6 მოთამაშისთვის. მეგობარს მხოლოდ ბმული სჭირდება: ანგარიში არ სჭირდება და არაფრის დაყენება არ უწევს.

## ფაილები
- `server.js` — სერვერი: ოთახები და თამაშის წესები
- `public/index.html` — თამაშის გვერდი (ბრაუზერში იხსნება)
- `package.json` — საჭირო პროგრამის სია

## ჯერ კომპიუტერზე გამოსაცდელად (არასავალდებულო)
1. დააინსტალირე Node.js (nodejs.org, ვერსია 18 ან ახალი).
2. ამ საქაღალდეში გახსენი ტერმინალი და ჩაწერე: `npm install`, შემდეგ `npm start`.
3. ბრაუზერში გახსენი http://localhost:3000. ორ ჩანართში შეგიძლია ორი მოთამაშის როლი ითამაშო.

## ინტერნეტში განთავსება უფასოდ (Render)
1. **GitHub:** შექმენი უფასო ანგარიში github.com-ზე. გააკეთე ახალი საცავი (New repository), სახელად `bluff`. დააჭირე „uploading an existing file“ და ატვირთე ამ საქაღალდის შიგთავსი (`server.js`, `package.json`, `.gitignore` და `public` საქაღალდე). `node_modules` არ ატვირთო.
2. **Render:** შექმენი უფასო ანგარიში render.com-ზე და შედი GitHub-ით.
3. დააჭირე **New + → Web Service** და აირჩიე შენი `bluff` საცავი.
4. პარამეტრები: Runtime — **Node**, Build Command — `npm install`, Start Command — `npm start`, Instance Type — **Free**.
5. დააჭირე **Create Web Service**. 2–3 წუთში გამოჩნდება ბმული (მაგალითად `https://bluff-xxxx.onrender.com`).
6. გახსენი ბმული, შეიყვანე სახელი, დააჭირე „ახალი ოთახი“, შემდეგ „ბმულის კოპირება“ და გაუგზავნე მეგობრებს.

## რა უნდა იცოდე
- უფასო Render-ი 15 წუთის უმოქმედობის შემდეგ „იძინებს“. პირველი გახსნისას ბმულს 30–60 წამი შეიძლება დასჭირდეს. თამაშის დაწყებამდე ერთხელ წინასწარ გახსენი.
- თუ სერვერი ხელახლა ჩაირთვება ან განახლდება, მიმდინარე თამაშები და ოთახები იშლება.
- თუ მოთამაშეს კავშირი გაუწყდა, გვერდის გადატვირთვით იმავე ოთახში ბრუნდება და თამაშს აგრძელებს. თუ 90 წამის განმავლობაში არ უპასუხა, მის ადგილს ბოტი იკავებს.
- ამ ვერსიაში კარტებს სერვერი ინახავს. მოწინააღმდეგის დახურული კარტები სხვის ბრაუზერამდე საერთოდ არ აღწევს.
